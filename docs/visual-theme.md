# 蓝白手帐视觉主题

本站使用六张本次生成的蓝色奶白纸艺图片：纸飞机与蝴蝶拼贴、飞行轨迹、手帐内页、贴纸、信笺、封面。它们是 AI 生成的装饰素材，不代表用户研究或本人独立绘制的作品；页面中保留相应说明。

- 首屏：拼贴主视觉，正文和操作保留为 HTML 文本。
- 灵感手帐：内页、贴纸与飞行轨迹，以小型纸卡呈现。
- 关于我：封面图；原来的 Canvas 雕塑收纳为可展开的交互小实验。
- 联系区：信笺作为淡背景，联系方式放在独立的可读表面上。

网页资源在 public/images/journal/，每张提供 640 和 1200 像素两个 WebP 版本，12 个文件总计约 1.24 MB。首屏优先加载，其他图片按需加载。图片属于装饰，使用空替代文本；含义由相邻的真实文本承载。

src/JournalVisuals.tsx 负责图片与双语手帐内容；src/journal.css 负责屏幕主题。主题使用奶白底、雾蓝与深蓝文字，保留原有功能及打印排版。动效尊重减少动态的系统设置。演示工具保留各自的配色，避免改变海报生成结果。
